    Git (read-only)
    
    
    This panel never runs a Git command that writes. No commit, no
      branch, no checkout, no reset, no push.
    
    
    
  
    

  
    
    
    What leaves this machine
    
    
    This workbench sends nothing. No model API, no telemetry, no
      external fonts, scripts or images. It talks only to
      127.0.0.1.
    
    
    If you then hand the generated prompt to Claude Code, Codex or another agent,
      that tool decides what to send and where, under its own policy. The two
      are separate; this page cannot make that decision for you.
    
    
    Compiling runs latexmk, and .latexmkrc is Perl: a build
      executes code from this repository. Only build repositories you trust.
